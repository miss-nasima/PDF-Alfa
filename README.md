# PDF Alfa

### Simple PDF Solutions

PDF Alfa is a simple web-based PDF tool built with **Python and Flask**.
I created this project to practice Python, Flask, file handling, and basic web development.

## Features

* Merge multiple PDF files
* Split PDF files
* Rotate PDF files
* Compress PDF files
* Custom output filename

## Built With

* Python
* Flask
* pypdf
* HTML
* CSS
* JavaScript

## How to Run

Clone the repository:

```bash
git clone https://github.com/miss-nasima/PDF-Alfa.git
cd PDF-Alfa
```

Create a virtual environment:

```bash
python -m venv .venv
```

Activate the virtual environment on Windows:

```bash
.venv\Scripts\Activate.ps1
```

Install the required packages:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python main.py
```

Then open:

```text
http://127.0.0.1:5000/
```
